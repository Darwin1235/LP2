# Sistema de Gestión de Alquiler de Maquinaria - Empresa M
**Curso:** Lenguaje de Programación II - Universidad de Huánuco (UDH)  
**Docente:** Mg. Omar Sulca Correa  

## Arquitectura
- **Backend:** PHP 8+ (PDO) bajo patrón MVC
- **Base de Datos:** MySQL (`bd_alquiler_maquinaria`)
- **Frontend:** HTML5, CSS3, JavaScript

## Instalación rápida
1. Importar `database/bd_alquiler_maquinaria.sql` en phpMyAdmin / MySQL.
2. Copiar `config/.env.example` o configurar credenciales en `config/Conexion.php`.
3. Ejecutar en servidor local (XAMPP/Laragon).
